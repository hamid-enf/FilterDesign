# اعتبارسنجی در برابر مرجع (SciPy)

## روش

هر الگوریتم کتابخانه با پیاده‌سازی مرجع SciPy مقایسه می‌شود:

```text
Reference (SciPy)          Implementation (FilterCoeff)
        ↓                             ↓
  ضرایب مرجع                ضرایب تولیدشده
        ↓                             ↓
  └────────── مقایسهٔ ضرایب ──────────┘
        ↓
  └────────── مقایسهٔ پاسخ فرکانسی ───┘
        ↓
  تحلیل خطا (max / RMS)
```

## ابزارها

| ابزار | نقش |
|---|---|
| `tools/reference/fce_dump.c` | طراحی ۴۰+ فیلتر ثابت + ۴ حالت خودکار + ۳ حالت fixed-point و چاپ JSON |
| `tools/reference/compare_reference.py` | طراحی معادل با SciPy و مقایسه |
| `make ref` | اجرای کل زنجیره |

نیازمندی: `python3` + `numpy` + `scipy` (فقط برای توسعه/تست — **هرگز** dependency فریم‌ور).

## موارد پوشش‌داده‌شده

### FIR (۱۴ مورد)
- هر ۵ پنجرهٔ اصلی + Tukey/Rectangular/Bartlett
- LP (فرد/زوج)، HP، BP، BS
- Kaiser با β دستی و خودکار (taps خودکار)
- Hilbert و Differentiator (با فرمول یکسان)
- نرمال‌سازی DC / Nyquist / PassbandPeak

### IIR (۲۲ مورد)
- هر ۵ خانواده × هر ۴ نوع پاسخ
- مرتبه‌های ۱ تا ۸
- dقت ضرایب: `max|Δ| < 2e-10` (معمولاً ~1e-15)

### مرتبهٔ خودکار (۴ مورد)
- `buttord` / `cheb1ord` / `cheb2ord` / `ellipord` — تطابق کامل مرتبه و فرکانس طراحی (LP/HP)؛ برای BP/BS تطابق مشخصات (تضعیف و ripple) چون فلسفهٔ طراحی لبه‌ها متفاوت است

### Fixed-Point (۳ مورد)
- Q15 FIR: بررسی محدوده، گرد کردن `round(c·scale)`، خطای بازسازی
- Q31 SOS بخش‌به‌بخش: محدوده و بازسازی
- Q15 SOS: پایداری پس از کمی‌سازی

### Sweep تصادفی (۶۰ مورد)
- خانواده × نوع تصادفی، مرتبهٔ ۲–۱۰، fs تصادفی ۸–۴۸kHz، fc تصادفی
- حداکثر خطای ضرایب در برابر SciPy: **~1e-13**

## تلورانس‌ها

| کمیت | تلورانس |
|---|---|
| ضرایب SOS (double) | 2e-10 |
| ضرایب FIR (double) | 2e-13 |

| مرتبهٔ خودکار | ±۲ |

## چرا این مقایسه «منصفانه» است

- پروتوتایپ‌های آنالوگ با **همان فرمول‌ها** (نه همان کد) پیاده شده‌اند.
- ترتیب/جفت‌کردن SOS با SciPy یکسان است (pairing='nearest')، پس مقایسهٔ ضریب-به-ضریب ممکن است.
- برای مواردی که فلسفهٔ طراحی متفاوت است (لبه‌های bandpass خودکار)، به‌جای مقایسهٔ ضرایب، **تحقق مشخصات** بررسی می‌شود.
