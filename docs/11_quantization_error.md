# فصل ۱۱ — خطای کمی‌سازی

## مفهوم

هر تبدیل float→fixed دقت را محدود می‌کند. این فصل توضیح می‌دهد که خطا چقدر است، کجا ظاهر می‌شود و کتابخانه چگونه آن را گزارش می‌کند.

## شهود

فرمت Q15 یعنی ۳۲۷۶۸ سطح بین −۱ و +۱. هر ضریب با خطای حداکثر `0.5/scale` گرد می‌شود. این خطا در حوزهٔ ضرایب کوچک است، اما در حوزهٔ پاسخ فرکانسی می‌تواند خودش را به صورت جابه‌جایی قطب/صفر (مخصوصاً برای فیلترهای باریک‌باند) نشان دهد.

## فرمول‌ها

```
q_i   = round(c_i · scale)
c̃_i  = q_i / scale

خطای مطلق:   e_i = |c_i − c̃_i|
خطای RMS:    √( (1/N) Σ e_i² )
خطای نسبی:   e_i / |c_i|      (برای c_i ≠ 0)
خطای پاسخ:   max |20 log10|H_ref(f)| − 20 log10|H_q(f)||   (در باند معنی‌دار)
```

حد خطای نظری (round-to-nearest): `max e_i ≤ 0.5/scale`

## مثال عددی — Q15

FIR Kaiser (مثال فصل ۱۰):

```
scale        = 157276.24
max|e_i|     = 3.09e-06      (حد نظری: 3.18e-06 ✓)
RMS error    = 1.91e-06
max rel. err = 1.5e-2        (برای ضرایب خیلی کوچکِ لبه‌ها)
خطای پاسخ   = 0.05 dB       (بالای 60- دسی‌بل)
```

## کد — دریافت همهٔ معیارها

```c
printf("max abs err : %.3e\n", result.q_max_abs_error);
printf("RMS err     : %.3e\n", result.q_rms_error);
printf("max rel err : %.3e\n", result.q_max_rel_error);
printf("resp err    : %.6f dB\n", result.quant_response_max_error_db);
```

## نکتهٔ مهم دربارهٔ «خطای پاسخ»

اختلاف دسی‌بلی دو پاسخ در **نول‌های عمیق** (مثلاً −100dB) بی‌معناست: جابه‌جاییِ ناچیزِ یک صفر، dB را ده‌ها واحد تغییر می‌دهد. بنابراین کتابخانه خطای پاسخ را فقط **بالای آستانهٔ −60dB** اندازه می‌گیرد — جایی که پاسخ واقعاً اهمیت دارد. در مستندات و report این موضوع ذکر می‌شود.

## مقایسهٔ Q15 در برابر Q31

| معیار | Q15 | Q31 |
|---|---|---|
| حداکثر خطای مطلق ضریب | ~3e-6 | ~5e-11 |
| خطای پاسخ | ~0.05 dB | < 0.001 dB |
| حافظه | ۲ بایت | ۴ بایت |

## استفادهٔ عملی

- اگر خطای پاسخ < 0.1dB نیاز دارید، Q15 تقریباً همیشه کافی است (برای فیلترهای معمولی).
- برای فیلترهای باریک‌باند (Q بالا) یا نیازهای دقیق، Q31 یا float32.
- همیشه `result.quant_stability_margin` را بعد از کمی‌سازی چک کنید (فصل ۱۲).
