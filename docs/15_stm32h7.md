# فصل ۱۵ — STM32H7

## مفهوم

هستهٔ FilterCoeff به هیچ‌چیز وابسته نیست: نه HAL، نه FreeRTOS، نه CMSIS. روی H7 کافی است فایل‌های `src/` را در build اضافه کنید و workspace را در RAM استاتیک قرار دهید.

## شهود

H7 یک Cortex-M7 با FPU سخت‌افزاری double است — یعنی محاسبات float64 تقریباً رایگان‌اند. پس می‌توانید ضرایب را **همان‌جا روی MCU** با دقت کامل تولید کنید.

## راه‌اندازی

```text
stm32h7_project/
├── Core/…
├── filtercoeff/
│   ├── include/filtercoeff.h, filtercoeff_config.h
│   └── src/fce_*.c          (همهٔ فایل‌ها)
```

در `filtercoeff_config.h` اندازه‌ها را متناسب کنید:

```c
#define FCE_MAX_FIR_TAPS  512
#define FCE_MAX_IIR_ORDER 16
```

## کد

```c
#include "filtercoeff.h"

/* workspace در RAM استاتیک (نه stack) */
static uint8_t fce_ws_mem[FCE_WS_SIZE];   /* FCE_WS_SIZE = fce_workspace_required_max() */

void audio_init(void)
{
    fce_spec_t sp;
    fce_result_t r;
    fce_workspace_t ws = { fce_ws_mem, sizeof(fce_ws_mem) };

    fce_spec_defaults(&sp);
    sp.kind = FCE_KIND_IIR;
    sp.iir_family = FCE_IIR_BUTTERWORTH;
    sp.iir_type  = FCE_IIR_LOWPASS;
    sp.fs = 48000; sp.fc1 = 5000; sp.order = 4;
    sp.qformat = FCE_QFORMAT_Q15;
    sp.precision = FCE_PRECISION_FLOAT32;

    if (fce_generate(&sp, &r, &ws) != FCE_OK)
        Error_Handler();

    /* تحویل به runtime (مثلاً CMSIS-DSP یا کتابخانهٔ خودتان) */
    arm_biquad_cascade_df1_init_f32(&S, r.num_sections,
                                    (float32_t*)r.sos_f32, state);
}
```

## نکات H7

| موضوع | توصیه |
|---|---|
| محل workspace | RAM استاتیک؛ اگر حافظهٔ CCMRAM اضافه دارید، `__attribute__((section(".ccmram")))` |
| دقت | از `FCE_PRECISION_FLOAT64` استفاده کنید؛ FPU double دارد |
| زمان طراحی | مرتبهٔ ۸ Butterworth ≈ 0.3ms @ 480MHz — در boot بی‌اهمیت است |
| کامپایلر | arm-none-eabi-gcc، `-std=c99 -O2 -ffast-math` اختیاری (با احتیاط) |
| کش | ضرایب فقط یک بار نوشته می‌شوند؛ بعد read-only — کش‌پسند |

## اندازه‌های حافظه (راهنما)

| طراحی | workspace |
|---|---|
| FIR 101 taps | ~4.3 kB |
| FIR 512 taps | ~21 kB |
| IIR order 8 | ~3 kB |
| IIR order 16 | ~6 kB |

## تست روی Host

کد تست/مثال‌ها با همان هدرها روی PC build می‌شوند:

```sh
make test        # همان کدی که روی H7 اجرا می‌شود
```
