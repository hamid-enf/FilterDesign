# فصل ۱۲ — پایداری عددی

## مفهوم

یک فیلتر IIR پایدار است اگر **همهٔ قطب‌ها داخل دایرهٔ واحد** باشند (`|p| < 1`). کتابخانه این موضوع را در دو مرحله بررسی می‌کند: بعد از طراحی (float) و بعد از کمی‌سازی (fixed-point).

## شهود

قطب‌های یک سکشن:

```
z² + a1·z + a2 = 0
        −a1 ± √(a1² − 4a2)
p1,2 = ───────────────────
                 2
```

اگر `a2` خیلی نزدیک ۱ باشد، قطب‌ها نزدیک دایرهٔ واحدند و یک خطای گرد کردن کوچک در `a2` می‌تواند فیلتر را ناپایدار کند. با Q15، `a2` فقط با دقت `1/32767 ≈ 3e-5` قابل نمایش است؛ پس فیلترهایی با `1 − |p| < 3e-5` در Q15 **ریسک ناپایداری** دارند.

## فرمول‌ها

```
max_radius = max|p_i| در همهٔ سکشن‌ها
margin     = 1 − max_radius
پایدار     ⟺ max_radius < 1
```

## آنچه کتابخانه گزارش می‌کند

| فیلد | معنی |
|---|---|
| `result.max_pole_radius` | بزرگ‌ترین شعاع قطب (float) |
| `result.stability_margin` | `1 − max_pole_radius` |
| `result.quant_max_pole_radius` | بزرگ‌ترین شعاع قطب پس از کمی‌سازی |
| `result.quant_stability_margin` | حاشیهٔ پایداری پس از کمی‌سازی |

و کدهای وضعیت:

| کد | معنی |
|---|---|
| `FCE_ERR_UNSTABLE` | طراحی float ناپایدار (نباید اتفاق بیفتد) |
| `FCE_ERR_QUANTIZATION` | کمی‌سازی فیلتر را ناپایدار کرده |
| `FCE_FLAG_SPEC_MARGINAL` | حاشیهٔ پایداری بسیار کم (`< 1e-9`) |

## مثال عددی — فیلتر باندگذر باریک

`fs=48k, BP 9900–10100 Hz, مرتبهٔ ۲, Q15`:

```
قطب‌ها: r ≈ 0.9992  (خیلی نزدیک به دایرهٔ واحد)
Q15: a2 با خطای ~3e-5 کمی‌سازی می‌شود
نتیجه: امکان ناپایداری → کتابخانه FCE_FLAG_QUANTIZATION_UNSTABLE یا
       حاشیهٔ بسیار کوچک را گزارش می‌کند
```

## کد — بررسی صریح

```c
if (result.max_pole_radius >= 1.0)
    /* هرگز نباید اتفاق بیفتد */
if (result.quant_max_pole_radius >= 1.0)
    /* کمی‌سازی فیلتر را خراب کرده: Q15 ندهید، Q31 یا float بدهید */
if (result.flags & FCE_FLAG_QUANTIZATION_UNSTABLE)
    /* خروجی قابل استفاده نیست */
```

همچنین می‌توانید هر مجموعه‌ی SOS دلخواه را بررسی کنید:

```c
double mr, margin;
fce_status_t st = fce_stability_sos(sos, n_sections, &mr, &margin);
/* st == FCE_OK ⟺ پایدار */
```

## استراتژی‌های کاهش ریسک

1. **Q31 به جای Q15** برای فیلترهای باریک‌باند (دقت 2^31).
2. **Section-wise scaling** — هر سکشن جداگانه، تا خطای نسبی کمینه شود.
3. **ترتیب پیش‌فرض (worst-last)** — سکشن‌های حساس آخر اجرا شوند.
4. **مرتبهٔ کمتر** — فیلتر با مرتبهٔ کمتر قطب‌های دورتری از دایرهٔ واحد دارد.

## جمع‌بندی

کتابخانه هرگز ضرایب ناپایدار را «بی‌صدا» تحویل نمی‌دهد: یا `status` غیر-OK می‌گیرید، یا پرچم هشدار ست می‌شود. این رفتار در تست‌ها پوشش داده شده است (`test_q15_unstable_detection`).
