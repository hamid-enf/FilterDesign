# فصل ۷ — ضرایب SOS / Biquad

## مفهوم

به جای یک تابع تبدیل مرتبهٔ بالا (که عددی بی‌ثبات است)، فیلتر به سکشن‌های مرتبهٔ دوم (Biquad) تجزیه می‌شود. خروجی کتابخانه آرایه‌ای از سکشن‌هاست:

```c
float32_t sos[][5] = {
    { b0, b1, b2, a1, a2 },   /* سکشن ۱ */
    { b0, b1, b2, a1, a2 },   /* سکشن ۲ */
    ...
};
```

## شهود

قطب‌های یک فیلتر مرتبهٔ ۱۰ اگر در یک مخرج درجهٔ ۱۰ قرار بگیرند، ضرایب آن چند مرتبه بزرگی اختلاف دارند و در float32 بی‌استفاده می‌شوند. با جفت‌کردن هر دو قطب (و دو صفر مجاور) در یک سکشن مرتبهٔ دوم، هر ضریب در محدودهٔ امن باقی می‌ماند و پایداری عددی حفظ می‌شود.

## قرارداد علامت (بسیار مهم)

```
y[n] = b0·x[n] + b1·x[n−1] + b2·x[n−2] − a1·y[n−1] − a2·y[n−2]
```

`a0 = 1` ضمنی است و در آرایه ذخیره نمی‌شود. این قرارداد با اکثر کتابخانه‌ها (CMSIS-DSP، scipy، MATLAB) هم‌خوان است؛ فقط ترتیب ستون‌ها را بررسی کنید (scipy: `[b0,b1,b2,a0,a1,a2]`).

## جفت‌کردن قطب-صفر (Pairing)

الگوریتم `nearest` (مطابق `scipy.signal.zpk2sos`):

1. «بدترین» قطب باقی‌مانده را بردار (نزدیک‌ترین به دایرهٔ واحد).
2. نزدیک‌ترین صفر به آن را جفت کن.
3. مزدوج‌ها را به سکشن اضافه کن.
4. تکرار تا اتمام.

نتیجه: بیشینهٔ بهرهٔ داخلی هر سکشن کمینه می‌شود → ریسک سرریز در fixed-point کم می‌شود.

## مرتب‌سازی سکشن‌ها (Ordering)

| استراتژی | رفتار |
|---|---|
| `FCE_SOS_ORDER_DEFAULT` (=POLE_RADIUS_ASC) | کم‌کیوترین اول، «بدترین» آخر (پیش‌فرض scipy) |
| `FCE_SOS_ORDER_POLE_RADIUS_DESC` | پرکیوترین اول |
| `FCE_SOS_ORDER_INTERNAL_GAIN` | بر اساس بهرهٔ داخلی اندازه‌گیری‌شده |

**چرا مرتب‌سازی مهم است؟** در fixed-point، سکشن با بهرهٔ بالا در ابتدا می‌تواند میانه (state) را سیر کند و سرریز کند. ترتیب پیش‌فرض (worst-last) معمولاً بهترین رفتار عددی را دارد.

## مثال عددی

Butterworth مرتبهٔ ۴ LP (`fs=48k, fc=5k`):

```c
static const float64_t sos[][5] = {
    { 0.00554177, 0.01108354, 0.00554177, -1.01554283, 0.28006372 },
    { 1.00000000, 2.00000000, 1.00000000, -1.28690544, 0.62210881 }
};
```

بررسی: بهرهٔ DC کل = Π (b0+b1+b2)/(1+a1+a2) = 1.

## API

```c
sp.sos_order = FCE_SOS_ORDER_DEFAULT;
...
result.sos_f64   /* float64 (همیشه) */
result.sos_f32   /* float32 (اگر precision=float32) */
result.num_sections
result.section_gains   /* بهرهٔ پیک هر سکشن */
```

## استفاده در کتابخانهٔ خارجی

```c
/* مثال: CMSIS-DSP */
arm_biquad_cascade_df1_init_f32(&S, result.num_sections, (float32_t*)result.sos_f32, state);

/* مثال: scipy convention — a0 را اضافه کنید */
for (s = 0; s < result.num_sections; s++) {
    scipy_sos[s] = { b0, b1, b2, 1.0f, a1, a2 };
}
```

## توصیه‌های عملی

- هرگز فیلترهای مرتبهٔ > ۲ را به صورت صورت/مخرج کلی پیاده‌سازی نکنید؛ همیشه SOS.
- برای fixed-point، استراتژی مقیاس‌گذاری `SECTION_WISE` با ordering پیش‌فرض بهترین ترکیب است.
