# فصل ۴ — پنجره‌های FIR

## مفهوم

پنجره، تابع وزن‌دهی متناهی است که پاسخ ضربهٔ ایده‌آل نامتناهی را به N ضریب محدود تبدیل می‌کند. انتخاب پنجره = انتخاب تعادل بین **ripple باند عبور** و **تضعیف باند قطع**.

## شهود

پنجرهٔ مستطیلی تیزترین انتقال را دارد اما لوب‌های کناری آن فقط ~13- دسی‌بل تضعیف دارند. پنجره‌های مثلثی/کوزینوسی لوب‌های کناری را نرم می‌کنند و Kaiser با یک پارامتر β این تعادل را پیوسته کنترل می‌کند.

## فرمول‌ها

برای `N` ضریب و `n = 0 … N−1`:

| پنجره | فرمول `w[n]` | تقریب تضعیف |
|---|---|---|
| Rectangular | `1` | ~13 dB |
| Hann | `0.5 (1 − cos(2πn/(N−1)))` | ~31 dB |
| Hamming | `0.54 − 0.46 cos(2πn/(N−1))` | ~43 dB |
| Blackman | `0.42 − 0.5 cos(·) + 0.08 cos(4πn/(N−1))` | ~58 dB |
| Kaiser | `I0(β√(1−t²)) / I0(β)` ، `t = 2n/(N−1) − 1` | متغیر |
| Blackman-Harris | `0.35875 − 0.48829 cos(·) + 0.14128 cos(2·) − 0.01168 cos(3·)` | ~92 dB |
| Bartlett | `1 − |2n/(N−1) − 1|` | ~26 dB |
| Tukey (α=0.5) | کسینوسی‌رامپ در لبه‌ها، ۱ در وسط | ~35 dB |

که در آن `I0` تابع بسل اصلاح‌شدهٔ نوع اول است:

```
I0(x) = Σ_k (x²/4)^k / (k!)²
```

## مثال عددی

مقادیر پنجرهٔ Hamming برای `N = 5`:

```
w = [0.08, 0.54, 1.00, 0.54, 0.08]
```

مقادیر پنجرهٔ Kaiser با β = 7.86 در مرکز: `w[(N−1)/2] = 1`.

## API

```c
sp.window = FCE_WIN_KAISER;
sp.kaiser_beta = 7.86;      /* 0 = محاسبهٔ خودکار از stopband_atten_db */
```

پنجره‌های موجود: `FCE_WIN_RECTANGULAR, FCE_WIN_HANN, FCE_WIN_HAMMING, FCE_WIN_BLACKMAN, FCE_WIN_KAISER, FCE_WIN_BLACKMAN_HARRIS, FCE_WIN_BARTLETT, FCE_WIN_TUKEY`

## کد (استفاده از مقادیر میانی)

```c
/* مشاهدهٔ مقادیر پنجره (No Black Box) */
for (uint32_t i = 0; i < result.num_taps; i++)
    printf("w[%u] = %.6f\n", i, result.fir_window[i]);
```

## ضرایب تولیدشده (مقایسهٔ پنجره‌ها)

فیلتر LP با `fs=48000, fc=5000, N=101` — تضعیف باند قطع اندازه‌گیری‌شده:

| پنجره | تضعیف اندازه‌گیری‌شده |
|---|---|
| Hamming | ~53 dB |
| Blackman | ~74 dB |
| Kaiser β=7.86 | ~80 dB |
| Blackman-Harris | ~92 dB |

## استفادهٔ عملی

- برای اکثر کارها **Kaiser** با β خودکار بهترین انتخاب است (فقط `stopband_atten_db` را بدهید).
- اگر حافظه محدود است و تضعیف ~40-50 dB کافی است، Hamming انتخاب سبکی است.
- برای کاربردهای measurement-grade، Blackman-Harris.
