# فصل ۱۶ — ESP32-C2

## مفهوم

ESP32-C2 یک RISC-V تک‌هسته (~120MHz) **بدون FPU** است. کتابخانه روی آن کار می‌کند، اما چون float64 نرم‌افزاری است، **تولید ضرایب روی خود C2 گران است**. الگوی پیشنهادی:

```text
Host (PC): طراحی ضرایب با دقت float64
    ↓  خروجی C (فصل ۱۴)
ESP32-C2: ضرایب static const + اجرا با کتابخانهٔ FIR/IIR خودتان
```

## شهود

C2 حافظهٔ کمی دارد (حدود ۵۷۶kB SRAM در بستهٔ ۲ مگابایتی فلش) و محاسبات ممیز شناور نرم‌افزاری‌اند. اما ضرایب را که یک بار از Host بگیرید، runtime فقط با int16/int32 کار می‌کند — که برای C2 ایده‌آل است.

## راه‌اندازی (IDF)

```text
components/filtercoeff/
├── include/
├── src/
├── CMakeLists.txt      (idf_component_register)
└── Kconfig
```

`CMakeLists.txt`:

```cmake
idf_component_register(
    SRCS "src/fce_math.c" "src/fce_fir.c" "src/fce_iir.c"
         "src/fce_quant.c" "src/fce_validate.c" "src/fce_sim.c"
         "src/fce_export.c" "src/fce_generate.c"
    INCLUDE_DIRS "include")
```

(اگر `FCE_ENABLE_EXPORT_STDIO=0` بگذارید، `fce_export_stdio.c` لازم نیست.)

## کد — استفاده از ضرایب تولیدشده در Host

```c
/* روی Host تولید شده: */
static const int16_t coeffs_q15[243] = { ... };

/* در C2: */
void app_main(void)
{
    /* مستقیم به runtime خودتان */
    my_fir_q15_init(&fir, coeffs_q15, 243, 1 << 15);
}
```

## کد — تولید روی خود C2 (اختیاری، کند)

```c
static uint8_t fce_ws_mem[16384];   /* استاتیک، نه stack! */

void design_on_target(void)
{
    fce_spec_t sp;
    fce_result_t r;
    fce_workspace_t ws = { fce_ws_mem, sizeof(fce_ws_mem) };

    fce_spec_defaults(&sp);
    sp.kind = FCE_KIND_FIR;
    sp.fir_type = FCE_FIR_LOWPASS;
    sp.fs = 16000; sp.fc1 = 2000; sp.num_taps = 0;   /* خودکار */
    sp.window = FCE_WIN_KAISER;
    sp.stopband_atten_db = 60;
    sp.transition_hz = 500;
    sp.qformat = FCE_QFORMAT_Q15;
    sp.precision = FCE_PRECISION_FLOAT32;

    if (fce_generate(&sp, &r, &ws) == FCE_OK)
        my_fir_q15_init(&fir, r.q15, r.num_taps, (int32_t)r.scale);
}
```

## نکات ESP32-C2

| موضوع | توصیه |
|---|---|
| دقت خروجی | `FCE_PRECISION_FLOAT32` — ضرایب float32 کافی‌اند |
| فرمت ایده‌آل | Q15 برای FIR؛ Q15/Q31 برای IIR با scaling مناسب |
| تولید روی دستگاه | فقط برای طراحی‌های کوچک (FIR ≤ 128 taps)؛ وگرنه از Host بیاورید |
| حافظه | `fce_workspace_required()` را برای حداقل اندازه چک کنید |
| Stack | workspace هرگز روی stack نگذارید (C2 stack کوچک است) |
| CI | همان تست‌های Host را اجرا کنید؛ هسته وابسته به پلتفرم نیست |

## اعتبارسنجی متقابل

ضرایبی که روی Host تولید می‌کنید از همان `fce_generate()` می‌آیند که ۱۰۵ بررسی SciPy و ۵۹۰۰+ تست واحد را پاس کرده است — یعنی دقیقاً همان ریاضیات، فقط روی پلتفرم دیگر.
