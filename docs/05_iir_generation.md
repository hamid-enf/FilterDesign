# فصل ۵ — تولید ضرایب IIR

## مفهوم

مسیر طراحی IIR در این کتابخانه دقیقاً مطابق روش کلاسیک (و مطابق پیاده‌سازی مرجع SciPy) است:

```text
پروتوتایپ آنالوگ Low-pass (ωc = 1)
        ↓ تبدیل فرکانس آنالوگ (lp2lp / lp2hp / lp2bp / lp2bs)
فیلتر آنالوگ هدف
        ↓ تبدیل دوخطی (Bilinear / Tustin) با prewarp
فیلتر دیجیتال (zpk)
        ↓ جفت‌کردن قطب-صفر (nearest) ← zpk2sos
SOS / Biquad
        ↓ توزیع بهره و مرتب‌سازی سکشن‌ها
ضرایب نهایی
```

## شهود

فیلترهای کلاسیک (Butterworth، Chebyshev، ...) ابتدا در دنیای آنالوگ تعریف می‌شوند، جایی که قطب‌ها با فرمول‌های بسته به‌دست می‌آیند. سپس با تبدیل دوخطی، صفحهٔ s به صفحهٔ z نگاشته می‌شود. چون تبدیل دوخطی فرکانس‌ها را «تاب می‌دهد» (warp)، قبل از آن فرکانس قطع دیجیتال را prewarp می‌کنیم تا نقطهٔ قطع دقیقاً درست بیفتد.

## فرمول‌ها

### Prewarp

```
ω_analog = 2 fs · tan(π f / fs)
```

### تبدیل دوخطی

```
s = 2 fs (z − 1) / (z + 1)

z_p = (2fs + p) / (2fs − p)          برای هر قطب p
z_z = (2fs + z) / (2fs − z)          برای هر صفر z
k'  = k · Re( Π(2fs − z) / Π(2fs − p) )
صفرهای واقع در بی‌نهایت → z = −1
```

### تبدیل‌های فرکانس آنالوگ (پروتوتایپ نرمال‌شده)

| تبدیل | جایگشت |
|---|---|
| lp→lp | `s → s/ω0` |
| lp→hp | `s → ω0/s` |
| lp→bp | `s → (s² + ω0²)/(s·BW)` |
| lp→bs | `s → s·BW/(s² + ω0²)` |

که `ω0 = √(ω1 ω2)` و `BW = ω2 − ω1`.

## مثال عددی

Butterworth مرتبهٔ ۴، LP، `fs = 48000`، `fc = 5000`:

```c
fce_spec_defaults(&sp);
sp.kind = FCE_KIND_IIR;
sp.iir_family = FCE_IIR_BUTTERWORTH;
sp.iir_type = FCE_IIR_LOWPASS;
sp.fs = 48000; sp.fc1 = 5000; sp.order = 4;
sp.precision = FCE_PRECISION_FLOAT64;
```

ضرایب SOS تولیدشده:

```c
static const float64_t sos[][5] = {
    { 0.00554177, 0.01108354, 0.00554177, -1.01554283, 0.28006372 },
    { 1.00000000, 2.00000000, 1.00000000, -1.28690544, 0.62210881 }
};
```

این ضرایب با `scipy.signal.butter(4, 5000, fs=48000, output='sos')` یکسان‌اند.

## محاسبهٔ خودکار مرتبه

اگر `order = 0`، کتابخانه مرتبه را از روی مشخصات باند محاسبه می‌کند (معادل `buttord`/`cheb1ord`/`cheb2ord`/`ellipord`):

```
Butterworth : N = ceil( log10((10^(0.1 gstop) − 1) / (10^(0.1 gpass) − 1))
                       / (2 log10(Ωs/Ωp)) )
Chebyshev   : N = ceil( acosh(√((Gstop−1)/(Gpass−1))) / acosh(Ωs/Ωp) )
Elliptic    : N = ceil( K(1/Ω²)·K'(m1) / (K'(1/Ω²)·K(m1)) )   (K = انتگرال بیضوی)
```

مثال mission: ۱ کیلوهرتز LP، `fs=10k`، تضعیف ۶۰dB در ۲ کیلوهرتز ← **مرتبهٔ ۹** (مطابق `buttord`).
